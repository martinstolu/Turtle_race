# 🏁 Turtle Racing Game

A colorful turtle racing game built with Python's `turtle` module! Bet on a turtle and watch it race across the screen. Will your pick win?

## 🎯 How It Works

1. Choose a color to bet on.
2. Turtles of different colors race randomly.
3. The game announces whether you won or lost.

## 🎨 Features

- 6 colorful turtle racers
- Random movement logic for suspense
- Simple user interaction via input dialog

## 🚀 How to Run

python main.py
Works best in a GUI-supported Python environment.
